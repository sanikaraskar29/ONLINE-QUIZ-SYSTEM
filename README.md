# Online Quiz System

A full-stack quiz application built with Spring Boot (backend) and HTML/CSS/JS (frontend). Users can create quizzes, view quizzes, and take quizzes online.

---

## Features

- Create quizzes with questions and multiple options  
- View all quizzes  
- Update or delete quizzes  
- Simple and interactive frontend interface  
- REST API support for backend operations
